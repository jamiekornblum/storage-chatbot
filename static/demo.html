Look Self Storage — Chatbot Demo

Your AI Chatbot is Running!

Click the orange button in the bottom-right corner to try it out.

Before going live: open app.py and fill in your real phone number, address, hours, and unit prices in the BUSINESS_INFO and UNITS sections at the top.

What the chatbot can do

  • Live Answer common questions — hours, features, policies, directions
  • Live Guide customers to the right unit — asks what they're storing and recommends a size
  • Live Show availability & pricing — reads from the UNITS dict in app.py in real time
  • Live Complete reservations — collects name, email, unit size, move-in date; saves to SQLite DB; sends confirmation emails
  • Live Automatic follow-up — emails customers 24 h after inquiry if staff haven't reached out yet

Embed on your website

Paste this before </body> on every page you want the chat on:

<script src="https://YOUR-BACKEND-URL/static/chatbot-widget.js" data-api-url="https://YOUR-BACKEND-URL/chat" data-title="Look Self Storage" data-color="#cc0000" data-header-color="#2a2a2a" ></script>

Replace YOUR-BACKEND-URL with the URL where you deploy this server (Render, Railway, Heroku, etc.).

Environment variables

Set these before starting the server:

Variable Description
ANTHROPIC_API_KEYYour Anthropic API keyrequired
NOTIFY_EMAILEmail address to receive new reservation alertsrecommended
SMTP_HOSTSMTP server hostname (e.g. smtp.gmail.com)
SMTP_PORTSMTP port — default 587
SMTP_USERSMTP login / sender address
SMTP_PASSSMTP password or app password
ADMIN_KEYPassword to access /admin/reservations
DB_PATHSQLite file path — default reservations.db
PORTHTTP port — default 5000

View reservations

All reservation leads are saved to reservations.db. You can view them as JSON at:

GET /admin/reservations?key=YOUR-ADMIN-KEY

Or open the .db file in any SQLite viewer (e.g. DB Browser for SQLite — free).

Start the server

pip install -r requirements.txt ANTHROPIC_API_KEY=sk-ant-... python app.py
